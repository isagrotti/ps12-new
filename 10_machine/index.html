<div class="textcontainer"> <p class="margin"> </p> <h3>Weeks 10-12: Machine Building</h3> <h4>Assignment: Build a Drawing Robot</h4> <p class = "margin"></p> Our initial idea was to make a drawing machine that uses three different colored pens. So our first step was assembling most of the machine and understanding the function of the different machine pieces. Next we got the CAD design of the pen holder and edited it in order to place three pens. Then we finished fully assembling everything. The next step was to make the machine work so we started with building the stepper motor circuit and connecting it to a code. That took a lot more time that we initially predicted because the cable we were using to connect the ESP32 to the computer wasn't workig properly and it took a lot of time for us to realise that that was the problem. After getting the machine to move properly we had to make it actually do its job and draw. </div>
